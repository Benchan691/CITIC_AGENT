The four setup situations

SituationCommandBehavior
Fresh install (no checkout)bash setup.sh (bootstrap)Prompts for repository URL, install path, branch; clones; re-execs the clone's setup
Existing checkout./setup.shInteractive: prereq checks → parameters → env files → Python env → harness build → plugin wiring → bundle registration → summary (starts nothing)
Audit only./setup.sh --checkReport-only; exit 1 when anything is missing/drifted; never writes
Non-interactive repair./setup.sh --plugins (+--rebuild)Reinstalls/repairs/rewires; no prompts, no env writing
Update./update.shRefuses dirty trees; fast-forward only; then setup.sh --plugins; restart manually

Configuration preparation (safe)

Setup writes apps/soc-agent/server/.env and vendor/deepseek-harness/.env (both chmod 600), prompts for secrets with echo disabled, and auto-generates the encryption key if left blank. Precedence: process env > server/.env > template. Required keys: SOC_ADMIN_EMAIL/SOC_ADMIN_PASSWORD (host refuses to start without them), APP_POSTGRES_URI + APP_SETTINGS_ENCRYPTION_KEY (login), ZIMBRA_HOST. The Splunk bridge enables only when SPLUNK_MCP_ENDPOINT and SPLUNK_TOKEN are both set.

Never paste real secrets into shell commands (shell history) or tickets. Use the prompts or edit the 0600 files.

Development startup and first verification

cd vendor/deepseek-harness
pnpm dsh web --no-open        # then open http://127.0.0.1:3080
  1. ./setup.sh --check — exits 0 only when everything is healthy.
  2. Open the app: the Sentinel login overlay must cover the shell until you sign in.
  3. Sign in with your own Zimbra credentials (not the admin pair); a private workspace appears under .data/soc-workspaces/<userId>/.
  4. Admin console (/admin) → Connections: run the Splunk / subscription checks (status only; config stays in the server env).
  5. As analyst: ask for mail folders or Splunk indexes (read tools auto-run in SOC mode); a mutation tool triggers an approval request.
  6. Create a draft and observe the card — sending is gated behind the explicit Send confirmation.
