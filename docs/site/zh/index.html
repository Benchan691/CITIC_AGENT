一屏系统摘要

这是什么？带工具调用 AI 的网页版安全运营调查助手；一个 Node 宿主进程 + Python 子进程。
谁在用？经认证的 SOC 分析师与管理员（独立静态管理员登录）。
两个 MCP 服务器soc_agent — 本地 Python stdio 服务器，28 个 Zimbra/订阅工具；splunk_mcp — 到外部官方 Splunk MCP 端点的客户端桥接，13 个只读工具。
安全模型仅允许列表内工具；默认只读；每工具 ask/auto/disabled；Full access vs SOC mode；邮件仅经界面 Send 确认投递；harness shell/文件系统工具禁用。
持久化PostgreSQL（会话、归属、加密配置）、.data/soc-workspaces/ 按用户工作区、被跟踪的 lib/ 生成产物。

产品概述（十分钟）

业务问题：分析师在 Zimbra 邮件、Splunk 告警与订阅记录之间往返。本产品把三者放进一个聊天窗口：分析师以本人身份登录，智能体经严格允许、默认只读的工具集调查。

刻意不做：不自主监控；Splunk 零变更（Splunk 代码已整体移除）；不部署检测；无模型驱动的邮件投递（草稿/转发只生成本地草稿）；不存储邮箱凭据；模型无 shell/文件系统工具。

运维警告。本文档不授权对 Splunk、Zimbra 或订阅服务的任何运维操作。
