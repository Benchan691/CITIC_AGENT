工具链与命令

安装/修复./setup.sh 或 ./setup.sh --plugins
宿主 JS 测试（42）pnpm test:host
SOC 浏览器包测试pnpm test
Python 测试（48）cd apps/soc-agent/server && uv sync --extra test && uv run pytest
重建 SOC 浏览器 bundlepnpm run build
浏览器 smoke/截图pnpm exec vitest run --config apps/soc-agent/tests/vitest.browser.config.mjs
启动应用pnpm dsh web --no-open

无活跃 lint/钩子（lefthook.yml 全注释）— 手动对齐周边风格。全部套件离线运行；无 skip；仓库根无 CI。

依赖模型与生成边界

根 pnpm workspace 与纯净 Harness vendor完全独立；36 个 SOC 包使用精确的 rc.2 兼容运行时 pin，不通过 vendor-relative workspace:* link 解析。服务器 pyproject.toml/uv.lock 是 Python 依赖来源。每个 packages/soc-agent-*/lib/ 都是 被跟踪的生成产物 — 其中 26 个包面生成浏览器 bundle；改后重建对应包并一起提交。

改一个 MCP 工具 — 六合同步清单

  1. tool-inventory.js 加名（标签/kind）。
  2. Python 在对应 register_tools 模块实现（读工具标 readOnlyHint；无 ctx/account_id）。
  3. cordis.patch.yml 原始允许列表。
  4. policy.js 从清单派生 — 分类逻辑不变则无需改。
  5. 双端测试（test_server_tools.py 精确集；policy.test.js/skills.test.js 计数 30/42/12）。
  6. 文档（工具目录、路由页、可追溯矩阵）。
  7. 覆盖缺口

vendor 由 tooling/verify-upstream.mjs --fresh 与官方 rc.2 archive 比对保持可复现；产品装配使用 cordis.patch.yml、根 workspace SOC 替代包与外置 citic-soc 预设 — 绝不编辑 vendored 源码。Schema 变更走新的 migrations/NNN_*.sql（advisory 锁、台账）。

覆盖缺口

浏览器 smoke 使用确定性 fixture 与截图基线；转发链路和 SQL 仍为分段/替身测试；setup.sh/update.sh 仍需部署环境校验；仓库根无 CI。细节：测试覆盖矩阵（中文）。
