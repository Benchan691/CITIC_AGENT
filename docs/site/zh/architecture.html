信任边界（摘要）

  1. 浏览器→宿主：会话 Cookie、同站检查、路由圈栏、特权 API 仅管理员。
  2. harness→工具：注册表限制 + 权威 tools/pre-execute 精确名允许列表。
  3. 宿主→MCP：每服务器原始允许列表、调用元数据、185 秒超时。
  4. Python→身份：soc_session_id → Postgres 会话 → 用户本人 Zimbra 令牌；180 秒预算。
  5. 输出→模型：Splunk 投影（PII 掩码、50 KB）、背景 64 KiB、附件限额。
  6. 变更→人：动作状态 + 审批；邮件额外界面确认。
  7. 补丁级：模型可见 shell/文件系统/子代理工具族禁用。
  8. 配置级：官方 Splunk MCP 连接必配 — setup/检查缺失即失败。
