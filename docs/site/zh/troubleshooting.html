故障排除

快速分诊

多数故障属于六类：缺环境变量、外部服务不可达、构建陈旧（被跟踪 lib/）、会话过期/被拒、策略拒绝（按设计工作）、或真正被拒的操作。先跑 ./setup.sh --check，再看下表。

症状领域

领域典型症状首选诊断
安装/更新缺前置；--check exit 1；更新拒绝脏树；Splunk 参数校验失败阅读检查输出；git status --porcelain --untracked-files=all；重跑 setup.sh --plugins
认证登录总失败；"new device" 提示；管理 RPC 403--check 的 Postgres 探测；/auth/me、/admin/auth/me；管理员会话在内存（重启登出）
归属workspace-invalid-path；跨用户 404/拒绝名称规则（单目录名）；归属声明按设计
MCP 发现工具缺失；"撞名"；"disabled by the administrator"对照工具目录；启动日志（桥接禁用？）；Access & approvals 状态
Splunk 桥接无工具；TLS 错误；185 秒超时；截断标记端点+令牌齐备？SPLUNK_VERIFY_SSL？收窄查询；标记即 50 KB 上限（按设计）
Zimbrazimbra_auth_error；query_validation_error；operation_disabled；filter_rules_changed重登；修查询形式（date:MM/DD/YYYY）；env 门是有意的；刷新指纹重试
订阅not_configured；email_server_unavailable；email_server_auth_failed管理状态检查；修三个 env 变量；查外部服务
附件attachment_too_large；attachment_encrypted；截断提示限额按设计（默认 10MB/200k，硬顶 100MB/2M）；同步 MarkItDown extras

UI/构建UI 改动不出现；/admin 503重建对应 SOC 浏览器 bundle；--rebuild 补 harness 产物
测试计数失败；源码护栏或浏览器 smoke 失败；schemastery 导入错误；Python 缺模块查看失败的包/浏览器输出；按六合同步清单更新；./setup.sh --plugins / uv sync --extra test

上报证据

git rev-parse HEAD 与分支、失败命令完整输出、含 soc_correlation_id 的日志行、策略意外时的确切工具名与管理端审批状态。分享前脱敏凭据与客户数据。
