运行时流程与界面

核对基准：提交 56c8dd21492a5c36cb9f3eaa3da01160aba40033（2026-09-12T07:22:44Z）· 文档核对日期 2026-09-12。

登录与身份

POST /auth/login → 同站检查 → Python 经 Zimbra 验证凭据 → Postgres 会话（Fernet 加密 Zimbra 令牌，24 h）→ soc_session Cookie。新登录撤销其他会话（单设备策略）。失败：一律 401（不回显密码）、session_expired（惰性删行）、上游令牌失效 → zimbra_auth_error 删会话强制重登。

只读 Splunk 请求

模型调用 mcp__splunk_mcp__splunk_* → 宿主门（读工具，默认 auto）→ 桥接 streamable HTTP + Bearer（185 秒）→ 外部服务器自带防护 → 结果投影（卡号/SSN 掩码、50 KB 截断）后进入模型上下文。未配置端点/令牌时桥接在启动时禁用（setup 也失败）。

邮件草稿 → 审阅 → 显式发送

zimbra_send_email / zimbra_forward_email 只生成本地草稿。投递仅经草稿卡：校验（≥1 收件人、主题）→ window.confirm → send-email RPC → 控制通道 → ZimbraMailService.send_email（门 ZIMBRA_ALLOW_SEND）→ 仅 result.sent === true 记为已发送。传输后丢响应为 operation_outcome_unknown，绝不重放。模型没有发信工具。

Full access vs SOC mode

部署默认存于加密设置；会话覆盖经菜单写入。Full access 直接运行每个被允许工具（连 disabled 也放行）；SOC mode 遵循每工具 ask/auto/disabled（默认变更 ask、读取 auto）。模式永不扩大允许列表。会话覆盖在登出/重启后清空。

界面区域

区域组件要点
登录门AuthGateSentinel 全屏遮罩；30 秒轮询；密码成功/失败均清空
动作模式菜单SocActionPolicyMenu采纳服务端确认值；畸形响应失败关闭
草稿卡EmailDraftToolview编辑→发送→已发送/失败/已丢弃；签名合并；显式确认
附件MarkItDown*双 worker；限额（5 文件/10MB/50MB/200k/500k）；截断提示
管理控制台AdminConsole连接状态（Splunk=实时桥接探测）、上下文、审批清单、只写凭据提供商
