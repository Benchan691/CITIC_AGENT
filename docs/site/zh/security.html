残余风险与建议

  1. 只读 Splunk 是组合性的 — 把命名栅栏测试作为发布门。
  2. Send 确认是界面级的 — 服务端强制认证+门+回执；如威胁模型要求可加确认令牌。
  3. CSRF 姿态依赖 SameSite/Origin；引入第三方源时考虑显式令牌。
  4. Splunk 栈已移除（原保留风险关闭）；相邻风险是检测技能陈旧。
  5. 仓库根无 CI — 把三个套件接入 CI。
  6. 被跟踪的 lib/ 与 soc-agent-scheduler 目录 — 见审计。
